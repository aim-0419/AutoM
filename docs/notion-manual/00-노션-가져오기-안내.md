# AutoM 이미지 사용자 매뉴얼

이 폴더는 Notion에 가져오기 쉬운 Markdown 문서와 화면 이미지로 구성되어 있습니다.

## 문서 구성

- `01-AutoM-사용자-매뉴얼.md`: 네이버 블로그 전용 프로그램 안내서
- `02-AutoM-Creator-사용자-매뉴얼.md`: 블로그·인스타그램·YouTube 통합 프로그램 안내서
- `images`: API Key와 개인정보가 없는 테스트 화면 이미지

## Notion에 넣는 방법

1. Notion에서 매뉴얼을 둘 페이지를 엽니다.
2. 왼쪽 메뉴의 `가져오기`에서 `Markdown & CSV`를 선택합니다.
3. 사용할 Markdown 문서를 가져옵니다.
4. 이미지가 자동으로 표시되지 않으면 `images` 폴더의 같은 이름 이미지를 해당 위치에 끌어다 놓습니다.
5. 고객에게 공개하기 전 실제 설치 파일 이름과 고객지원 연락처를 마지막으로 확인합니다.

> 화면 이미지는 빈 테스트 환경에서 촬영했습니다. 실제 사용자의 API Key, 로그인 정보와 발행 기록은 포함되어 있지 않습니다.

## 권장 Notion 구성

첫 페이지에는 프로그램 소개와 `처음 5분 시작하기`만 두고, 상세 기능은 하위 페이지나 목차로 구분하는 것이 좋습니다.

1. 프로그램 소개
2. 설치 후 처음 설정
3. 메뉴별 사용 방법
4. 실제 발행 전 확인사항
5. 오류 해결
6. 자주 묻는 질문
