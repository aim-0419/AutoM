# AutoM 사용자 안내서

## 프로그램 종류

- **AutoM**: 네이버 블로그 글 생성과 발행에 사용하는 전용 프로그램
- **AutoM Creator**: 블로그, 인스타그램 카드뉴스, YouTube 영상 초안을 한 프로그램에서 관리

## 처음 시작할 때

1. 설정 화면에서 사용할 텍스트 AI와 이미지 AI를 선택합니다.
2. 각 AI 서비스의 API 키를 입력하고 설정을 저장합니다.
3. 블로그 또는 인스타그램 자동 발행이 필요하면 해당 플랫폼에서 로그인합니다.
4. 생성 결과를 저장할 출력 폴더와 기본 발행 설정을 확인합니다.

API 키는 운영체제의 암호화 저장 기능으로 보관되며 화면에는 일부만 표시됩니다. 새 컴퓨터에는 기존 컴퓨터의 키와 로그인 세션이 자동으로 복사되지 않습니다.

## 블로그

1. 키워드를 한 줄에 하나씩 입력합니다.
2. 필요하면 키워드 자동추천을 사용합니다.
3. 발행 모드를 선택합니다.
4. 생성 시작을 누르고 결과를 확인합니다.

발행 모드:

- **반자동**: 글과 이미지만 생성하고 로컬 폴더에 저장
- **확인 후 발행**: 미리보기에서 제목과 본문을 확인한 뒤 사용자가 발행
- **완전자동**: 생성이 끝나면 즉시 발행
- **예약발행**: 지정한 시각을 네이버 예약 발행 시각으로 등록

완전자동은 여러 키워드를 순서대로 처리하며 설정된 간격을 둡니다. AI가 만든 건강, 금융, 법률 등 중요한 정보는 공개 전에 사람이 사실성을 확인해야 합니다.

## 인스타그램

1. 인스타그램 탭에서 로그인 상태를 확인합니다.
2. 주제를 입력하거나 키워드 자동추천을 사용합니다.
3. 카드 수를 선택하고 카드 생성을 누릅니다.
4. 생성된 카드 이미지와 게시 문구를 확인합니다.
5. 발행 버튼을 누르기 전에 계정, 이미지 순서, 문구를 다시 확인합니다.

카드 이미지는 글자 대비와 단어 단위 줄바꿈을 적용하지만, 긴 고유명사와 숫자는 사람이 최종 확인하는 것이 좋습니다.

## YouTube

1. 채널 핵심 주제, 주요 시청자, 제작자의 실제 관점이나 경험을 입력합니다.
2. 쇼츠 또는 롱폼과 영상 길이, 장면 수, 구성 방식을 선택합니다.
3. 영상과 대본 생성을 실행합니다.
4. 출력 폴더의 WebM, 대본, SRT 자막, 썸네일, 메타데이터를 확인합니다.
5. CapCut에서 편집하고 본인의 목소리를 녹음합니다.
6. 업로드 버튼으로 YouTube 업로드 페이지를 엽니다.

이 기능은 수익 창출 승인이나 정책 준수를 보장하지 않습니다. 반복적인 대량 콘텐츠가 되지 않도록 제작자의 실제 경험, 설명, 편집을 추가해야 합니다.

## 발행 기록

발행 기록에서는 블로그, 인스타그램, YouTube 결과를 플랫폼별로 확인할 수 있습니다. 기록은 프로그램 설치 폴더가 아니라 Windows 사용자 데이터 폴더에 남으므로 프로그램 파일을 지워도 같은 컴퓨터와 사용자 계정에서는 다시 표시될 수 있습니다.

## 주의 사항

- 연결 테스트, 추천, 생성은 외부 AI 비용이 발생할 수 있습니다.
- 세션 초기화는 저장된 로그인 상태를 지우므로 계정을 바꿀 때만 사용합니다.
- 실제 발행 전에 공개 여부, 예약 시각, 제목, 본문, 이미지 순서를 확인합니다.
- 플랫폼 화면이 변경되면 자동화가 일시적으로 실패할 수 있습니다.
- 실패하면 화면의 오류 문구와 `logs` 폴더의 기록을 확인합니다.

## 문제 해결

- **API 키 오류**: 공급자 선택과 해당 공급자의 키가 일치하는지 확인하고 저장합니다.
- **네이버 또는 인스타그램 로그인이 풀림**: 로그인 화면에서 다시 로그인합니다. 계속 실패할 때만 세션을 초기화합니다.
- **네이버 로그인이 유지되지 않는다고 나올 때**: 로그인 창의 **"로그인 상태 유지"가 켜져 있어야** 합니다.
  프로그램이 자동으로 켜지만, 화면이 늦게 열리는 컴퓨터에서는 꺼진 채로 진행될 수 있습니다.
  이 항목이 꺼져 있으면 로그인 창을 닫는 순간 로그인이 사라져, 발행할 때 로그인이 풀린 것처럼 실패합니다.
  로그인 창이 뜨면 이 항목을 직접 확인하고 켠 뒤 로그인해 주세요.
- **AutoM과 AutoM Creator는 설정을 공유하지 않습니다**: 두 앱은 API 키, 블로그 ID, 로그인 상태를 각각 따로 저장합니다.
  한쪽에서 설정했더라도 다른 앱에서 처음 쓸 때는 블로그 ID 입력과 로그인을 다시 해야 합니다.
- **브라우저 실행 파일 오류**: 설치본에 Chromium이 포함되어 있는지 확인합니다. 개발 환경은 `npx playwright install chromium`이 필요합니다.
- **발행 실패**: 플랫폼의 글쓰기 화면 구조가 바뀌었는지 확인하고 로그와 실패 스크린샷을 개발자에게 전달합니다.
